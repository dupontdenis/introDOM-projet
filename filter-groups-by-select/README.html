Filtrer les groupes avec un menu déroulant

Cette page filtre les groupes d’étudiants à l’aide d’un menu déroulant. Les options sont créées à partir des groupes présents dans les données.

Fonctionnement

  • Object.groupBy() regroupe les étudiants selon leur propriété group, puis Object.entries() fournit les paires groupe et membres.
  • Les noms de groupes uniques sont ajoutés au menu avec document.createElement() et append().
  • renderGroups(query) affiche tous les groupes si la requête est vide, ou uniquement le groupe sélectionné.
  • L’événement change relance le rendu après chaque sélection. Un premier rendu affiche tous les groupes au chargement.

À essayer

Changez le groupe sélectionné, puis ajoutez un étudiant d’un nouveau groupe dans data.mjs. Rechargez la page pour vérifier que le groupe apparaît dans le menu.

Ouvrez index.html depuis un serveur web local. Cet exercice utilise des modules JavaScript et Object.groupBy(), qui nécessite un navigateur moderne.
